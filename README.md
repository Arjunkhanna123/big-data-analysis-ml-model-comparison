# Big Data Analysis – ML Model Comparison

## Overview
This project focuses on performing data analysis and implementing multiple machine learning models to compare their performance on the same dataset. The experiments were conducted using Google Colab.

## Models Implemented
- Model 1  Logistic Regression
- Model 2  Random Forest 
- Model 3  XG Boost
- Model 4  Multinominal Naive Bayes

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Google Colab

## Workflow
- Data preprocessing and cleaning
- Feature extraction and preparation
- Training multiple ML models
- Model evaluation and comparison using metrics

## Note
This project was developed as part of an academic big data analysis exercise.
